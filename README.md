# 🚀 ALGO FLOW QUEST
**Gamified Learning — Algoritma & Flowchart**

## Target Siswa
- **Jenjang**: SMP/MTs & SMA/SMK (Siswa Pemula Informatika)

## Teknologi
- **HTML5**
- **CSS3** (Flexbox, Grid, Responsive Design)
- **JavaScript Vanilla** (ES6+)
- **SVG & Canvas**
- **Web Audio API**
- **localStorage**

## Cara Menjalankan
1. Ekstrak berkas `ALGO-FLOW-QUEST.zip`.
2. Buka folder proyek.
3. Klik ganda pada berkas `index.html` untuk menjalankan game di browser Anda.

## GitHub Pages Compatibility
- Upload seluruh isi folder ke repository GitHub Anda.
- Pastikan berkas `index.html` berada di root proyek.
- Pilih branch `main` pada Settings > Pages.

## Mode
- **Offline / Local Storage** (Tidak memerlukan Backend / Server)
